# GATE PREP

A personal, offline-capable workspace for GATE CSE preparation.

## Foundation

React + TypeScript + Vite; Home, Test Series, Quizzes, Notes, Abstractions, and Cheat Sheets views; live countdown to the configured GATE CSE 2027 date; responsive dark interface; GitHub Pages workflow; service-worker caching for repeat/offline visits.

## Local development

Requires Node.js 20.19+.

    npm install
    npm run dev
    npm run typecheck
    npm run build

See guide/ for architecture, project structure, design system, offline behaviour, future integrations, roadmap, and checklists.

This foundation contains empty workspace templates only. Study content, question banks, statistics, import/export, backup, authentication, and backend integration are not included.
